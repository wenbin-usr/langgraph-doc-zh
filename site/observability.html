LangSmith 可观测性

追踪（Traces）是智能体从输入到输出所经历的一系列步骤。其中每个单独的步骤都由一次运行表示。你可以使用 LangSmith 将这些执行步骤可视化。要使用它，请为你的智能体启用追踪。这让你能够执行以下操作：

  • 调试本地运行的智能体。
  • 评估智能体性能。
  • 监控智能体。

前置条件#

在开始之前，请确保你已具备以下条件：

  • 一个 LangSmith 账户：在 smith.langchain.com 免费注册或登录。
  • 一个 LangSmith API 密钥：请遵循创建 API 密钥指南。

启用追踪#

ℹ注意

在基于智能体的工作区中，发送追踪之前请先创建一个智能体。使用智能体寻址来选择其标识符和环境。如果某个集成需要 project_name，请使用所选环境的 1 作为兼容值。

要为你的智能体启用追踪，请设置以下环境变量：

bash
export LANGSMITH_AGENT_ID="<your-agent-id>"
export LANGSMITH_AGENT_ENVIRONMENT="local"
export LANGSMITH_TRACING=true
export LANGSMITH_API_KEY=<your-api-key>

追踪将显示在设置期间配置的目标位置。

更多信息，请参阅使用 LangGraph 追踪。

选择性追踪#

你可以选择使用 LangSmith 的 tracing_context 上下文管理器来追踪智能体的特定调用或部分：

python
import langsmith as ls

# This WILL be traced
with ls.tracing_context(enabled=True):
    agent.invoke({"messages": [{"role": "user", "content": "Send a test email to alice@example.com"}]})

# This will NOT be traced (if LANGSMITH_TRACING is not set)
agent.invoke({"messages": [{"role": "user", "content": "Send another email"}]})

选择智能体与环境#

使用 LANGSMITH_AGENT_ID 和 LANGSMITH_AGENT_ENVIRONMENT 来选择已注册的智能体和环境。如需按请求路由，请在代码中传入智能体地址。请参阅将追踪记录到智能体。

基于项目的工作区与自托管 LangSmith

设置 LANGSMITH_PROJECT 为追踪项目名称，而不是设置智能体相关变量。对于在基于智能体的工作区中需要 project_name 的集成，请使用环境的 2 作为兼容值。

为追踪添加元数据#

你可以使用自定义元数据和标签来注解你的追踪：

python
response = agent.invoke(
    {"messages": [{"role": "user", "content": "Send a welcome email"}]},
    config={
        "tags": ["production", "email-assistant", "v1.0"],
        "metadata": {
            "user_id": "user_123",
            "session_id": "session_456",
            "environment": "production"
        }
    }
)

tracing_context 同样接受标签和元数据，以实现更精细的控制：

python
with ls.tracing_context(
    enabled=True,
    tags=["production", "email-assistant", "v1.0"],
    metadata={"user_id": "user_123", "session_id": "session_456", "environment": "production"}):
    response = agent.invoke(
        {"messages": [{"role": "user", "content": "Send a welcome email"}]}
    )

这些自定义元数据和标签将附加到 LangSmith 中的追踪上。

💡提示

如需进一步了解如何使用追踪来调试、评估和监控你的智能体，请参阅 LangSmith 文档。

使用匿名化器防止在追踪中记录敏感数据#

你可能希望遮蔽敏感数据，以免其被记录到 LangSmith。你可以创建匿名化器，并通过配置将它们应用到 你的图。此示例将从发送到 LangSmith 的追踪中隐去任何匹配社会安全号码格式 XXX-XX-XXXX 的内容。

python
from langchain_core.tracers.langchain import LangChainTracer
from langgraph.graph import StateGraph, MessagesState
from langsmith import Client
from langsmith.anonymizer import create_anonymizer

anonymizer = create_anonymizer([
    # Matches SSNs
    { "pattern": r"\b\d{3}-?\d{2}-?\d{4}\b", "replace": "<ssn>" }
])

tracer_client = Client(anonymizer=anonymizer)
tracer = LangChainTracer(client=tracer_client)
# Define the graph
graph = (
    StateGraph(MessagesState)
    ...
    .compile()
    .with_config({'callbacks': [tracer]})
)

通过 MCP 将这些文档连接到你所选的智能体，以获取实时答案。
