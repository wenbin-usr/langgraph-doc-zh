Graph API 构建清单

在使用 Graph API 构建时，确定状态、控制流、Send、Command 和节点选项。

本指南梳理构建图时需要做出的决策。有关安装和端到端智能体示例，参见 LangGraph 快速入门。有关设计讲解，参见 用 Graph API 思考。有关概念，参见 Graph API 概览。要在 Graph API 与 Functional API 之间做选择，参见 在 Graph API 与 Functional API 之间选择。

构建图#

请按顺序处理这些决策。每个步骤都包含一个简短示例，并链接到完整操作指南。

1. 定义共享状态

确定节点之间共享哪些数据，以及更新如何合并。

  • 选择一种 schema（TypedDict、dataclass，或在 TypeScript 中使用 StateSchema）。
  • 为多个节点写入的键添加归并函数（例如追加消息）。
  • 当图需要向调用方隐藏内部通道时，使用私有 schema 或输入/输出 schema。
python
import operator
from typing import Annotated

from typing_extensions import TypedDict


class State(TypedDict):
    foo: int
    bar: Annotated[list[str], operator.add]

这里 foo 会被覆盖。bar 通过 operator.add 追加。

有关 schema、归并函数、消息和私有状态，参见定义和更新状态。

2. 选择控制流

确定工作如何在节点之间流转。

  • 顺序：按固定顺序执行的步骤。
  • 分支：条件边根据状态选择下一个节点。
  • 并行：扇出到多个节点，然后再扇入（通常配合归并函数）。
  • 循环：循环直到满足终止条件，或通过递归限制限制运行次数。

以下顺序流程检查数字是否为偶数，然后格式化一条消息：

python
from typing_extensions import TypedDict

from langgraph.graph import END, START, StateGraph


class State(TypedDict):
    number: int
    is_even: bool
    message: str


def check_even(state: State):
    return {"is_even": state["number"] % 2 == 0}


def format_message(state: State):
    return {
        "message": (
            "The number is even." if state["is_even"] else "The number is odd."
        )
    }


workflow = StateGraph(State)
workflow.add_node("check_even", check_even)
workflow.add_node("format_message", format_message)
workflow.add_edge(START, "check_even")
workflow.add_edge("check_even", "format_message")
workflow.add_edge("format_message", END)
graph = workflow.compile()

graph.invoke({"number": 7})

有关分支、并行路径和循环，参见构建顺序、分支和循环。

3. 决定是否需要 Send 或 Command

大多数图只需要节点、边和条件边。除非遇到下面的情况，否则把路由放在边里。有关模式和示例，参见使用 Send 和 Command。

当默认模型不够用时，再使用这些扩展机制：

  • 当你必须为每个条目运行一次相同节点、每个条目有自己的输入，且条目数量只有运行时才能确定时（map-reduce / 编排器-工作器），使用 0。
  • 当某个步骤必须同时更新状态并选择下一个节点、在中断后恢复，或从工具更新状态时，使用 0。
python
from typing import Literal

from langgraph.types import Command, Send


# Send: fan out one worker per item
def continue_to_jokes(state: OverallState):
    return [Send("generate_joke", {"subject": s}) for s in state["subjects"]]


# Command: update state and route in one return
def my_node(state: State) -> Command[Literal["my_other_node"]]:
    return Command(
        update={"foo": "bar"},
        goto="my_other_node",
    )

4. 按需配置节点

当可靠性或成本很重要时，添加运行时选项：

  • 为不稳定或缓慢的步骤设置重试和超时
  • 错误处理器和图级别的节点默认值
  • 为开销大的重复工作启用缓存
  • 为不应放入状态的依赖项设置运行时上下文或配置
python
from langgraph.types import RetryPolicy

builder.add_node(
    "node_name",
    node_function,
    retry_policy=RetryPolicy(),
)

参见配置节点。

5. 可视化图

渲染 Mermaid 或 PNG 图表，以检查拓扑结构并调试路由。

python
print(graph.get_graph().draw_mermaid())

参见可视化你的图。
