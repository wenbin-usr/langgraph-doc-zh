概览

将 LangGraph 智能体渲染到前端

构建能够实时可视化 LangGraph 流水线的前端。这些模式展示了如何渲染多步图执行，并呈现每个节点的状态以及来自自定义 StateGraph 工作流的流式输出内容。

LangGraph 的前端优势在于，UI 可以遵循与图相同的结构。节点、状态键、检查点、中断、子图和流式消息都是可见的运行时概念，因此你可以构建出能解释系统正在做什么的界面，而不是把执行过程隐藏在一段助手消息之后。

ℹ注意

这些模式使用 v1 版本的前端 SDK 包。如果你使用的是更早的版本，请参阅 React、Vue、Svelte 和 Angular 的迁移指南。

架构#

LangGraph 图由通过边连接的具名节点组成。每个节点执行一个步骤（分类、检索、分析、综合），并将输出写入特定的状态键。在前端，SDK 的流句柄提供对节点输出、流式 token 和已发现子图的响应式访问，因此你可以将每个节点映射到一张 UI 卡片。

python
from langgraph.graph import StateGraph, MessagesState, START, END

class State(MessagesState):
    classification: str
    research: str
    analysis: str
    synthesis: str

graph = StateGraph(State)
graph.add_node("classify", classify_node)
graph.add_node("do_research", research_node)
graph.add_node("analyze", analyze_node)
graph.add_node("synthesize", synthesize_node)
graph.add_edge(START, "classify")
graph.add_edge("classify", "do_research")
graph.add_edge("do_research", "analyze")
graph.add_edge("analyze", "synthesize")
graph.add_edge("synthesize", END)

app = graph.compile()

在前端，0 暴露了用于图节点发现的 stream.subgraphs，以及诸如 useMessages(stream, node) 之类的选择器辅助函数，用于获取节点范围内的流式内容。当你需要诸如最终的 synthesis 这类字段时，stream.values 仍会持有完整的图状态。Angular 通过 5 使用相同形态的流 API。

ts
import { useStream } from "@langchain/react";

function Pipeline() {
  const stream = useStream<typeof graph>({
    apiUrl: "http://localhost:2024",
    assistantId: "pipeline",
  });

  const classification = stream.values?.classification;
  const research = stream.values?.research;
  const analysis = stream.values?.analysis;
  const graphNodes = [...stream.subgraphs.values()];
}

与聊天流的区别#

自定义图通常支撑着产品工作流：检索流水线、审批流、数据流水线、数据增强、代码审查、规划以及多步分析。前端 SDK 让你可以使用图原生信号来渲染这些工作流：

运行时概念前端用户体验
具名节点每个图节点对应一张卡片、一个时间线步骤或一个状态徽章。
状态键为分类、来源、分析和最终综合等类型化输出提供专门的 UI 区域。
流式元数据将部分消息路由到产生它的节点。
检查点检查或从先前的图状态恢复，用于调试和审计。
中断暂停某个节点以等待人工输入、审批或修正，然后再继续。
子图仅在用户需要更多细节时才展示嵌套执行。

由于 SDK 直接暴露这些概念，你可以从简单的聊天面板扩展到完整的工作流调试器，而无需更改后端协议。

模式#

图执行

可视化多步图流水线，并呈现每个节点的状态和流式内容。

自定义流通道

将自定义的服务端数据流式输出到前端，并使用 useExtension 和 useChannel 读取。

相关模式#

LangChain 前端模式——Markdown 消息、工具调用、人在回路、可恢复流和时间旅行——适用于任何 LangGraph 图。无论你使用 createAgent、createDeepAgent 还是自定义 StateGraph，流 API 都提供相同的核心数据模型。
