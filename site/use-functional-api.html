Functional API 构建清单

决定如何使用 Functional API 组合入口点、任务、流式输出、中断与记忆。

本指南将逐一说明使用 Functional API 构建应用时所做的一系列决策。安装步骤与端到端智能体示例，请参见 LangGraph 快速开始。设计思路讲解，请参见 Functional API 设计思路。概念说明，请参见 Functional API 概览。如需在 Graph API 与 Functional API 之间做选择，请参见 在 Graph API 与 Functional API 之间选择。

构建你的工作流#

请按顺序逐项处理这些决策。每个步骤都链接到对应的操作指南，其中包含完整做法。

1. 组合工作流

定义一个入口点，将工作单元封装为任务，并选择各步骤之间的连接方式。

  • 从单个入口点开始，并将输入作为单个参数传入（通常是 dict）。
  • 对于需要独立检查点和重试的离散工作，使用任务。
  • 当各步骤相互独立时，使用并行任务进行扇出。
  • 需要组合时，调用已编译的 Graph API 图或另一个入口点。

参见 组合 Functional API 工作流。

2. 配置任务

当步骤可能失败、挂起或重复时，添加可靠性控制。

  • 针对瞬时失败的重试
  • 针对缓慢任务或入口点的超时
  • 针对开销大的重复工作的缓存
  • 出错后恢复，且无需重做已完成的任务

参见 配置 Functional API 任务。

3. 流式输出进度

在工作流运行期间流式输出更新、模型 token 或自定义数据。

参见 使用 Functional API 进行流式输出。

4. 添加人在回路

使用中断暂停以进行审批或工具调用审查，然后使用 Command 恢复执行。

参见 使用 Functional API 添加人在回路。

5. 添加记忆

使用检查点器保存短期线程状态，使用存储保存长期数据。

参见 使用 Functional API 添加记忆。
