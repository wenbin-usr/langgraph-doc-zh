LangGraph/部署/运行本地服务器
部署

运行本地服务器

本指南介绍如何在本地运行 LangGraph 智能体。

前置条件#

开始之前，请确保已准备好以下内容：

  • 一个 LangSmith 的 API 密钥——注册免费

1. 安装 LangGraph CLI#

bash
# Python >= 3.11 is required.
pip install -U "langgraph-cli[inmem]"
bash
# Python >= 3.11 is required.
uv add "langgraph-cli[inmem]"

2. 创建 LangGraph 智能体#

使用 0 模板 创建智能体代码。该模板展示了一个单节点图，你可以用自己的逻辑对其进行扩展。

shell
langgraph new path/to/your/app --template new-langgraph-project-python
💡提示

其他模板 如果在使用 langgraph new 时未指定模板，你将看到一个交互式菜单，可从中选择可用的模板。

3. 安装依赖#

在新建 LangGraph 应用的根目录下，以 edit 模式安装依赖，这样服务器就会使用你的本地改动：

bash
cd path/to/your/app
pip install -e .
bash
cd path/to/your/app
uv sync

4. 创建 .env 文件#

ℹ注意

在基于智能体的工作区中，发送追踪前需先创建智能体。使用智能体寻址选择其标识符和环境。如果某个集成需要 project_name，请使用所选环境的 1 作为兼容值。

在新建 LangGraph 应用的根目录中会有一个 .env.example 文件。请在根目录下创建 .env 文件，并把 .env.example 的内容复制进去，填入所需的 API 密钥：

bash
LANGSMITH_API_KEY=lsv2...
LANGSMITH_AGENT_ID="<your-agent-id>"
LANGSMITH_AGENT_ENVIRONMENT="local"

5. 启动 Agent Server#

在本地启动 LangGraph API 服务器：

shell
langgraph dev

示例输出：

text

langgraph dev 命令以内存模式启动 Agent Server。该模式适用于开发和测试。生产环境请部署可访问持久化存储后端的 Agent Server。更多信息请参见平台设置概览。

6. 在 Studio 中测试你的智能体#

Studio 是一个专用 UI，你可以将它连接到 LangGraph API 服务器，从而在本地可视化、交互和调试你的智能体。访问 langgraph dev 命令输出中提供的 URL，即可在 Studio 中测试你的图：

text
>    - LangGraph Studio Web UI: https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024

如果 Agent Server 运行在自定义主机/端口上，请更新 URL 中的 baseUrl 查询参数。例如，若服务器运行在 http://myhost:3000 上：

text
https://smith.langchain.com/studio/?baseUrl=http://myhost:3000
Safari 兼容性

由于 Safari 在连接 localhost 服务器时存在限制，请在命令中使用 --tunnel 标志创建安全隧道：

shell
langgraph dev --tunnel

7. 测试 API#

  1. 安装 LangGraph Python SDK：
    shell
     pip install langgraph-sdk
  2. 向助手发送消息（无线程运行）：
    python
     from langgraph_sdk import get_client
 import asyncio

 client = get_client(url="http://localhost:2024")

 async def main():
     async for chunk in client.runs.stream(
         None,  # Threadless run
         "agent", # Name of assistant. Defined in langgraph.json.
         input={
         "messages": [{
             "role": "human",
             "content": "What is LangGraph?",
             }],
         },
     ):
         print(f"Receiving new event of type: {chunk.event}...")
         print(chunk.data)
         print("\n\n")

 asyncio.run(main())
  1. 安装 LangGraph Python SDK：
    shell
     pip install langgraph-sdk
  2. 向助手发送消息（无线程运行）：
    python
     from langgraph_sdk import get_sync_client

 client = get_sync_client(url="http://localhost:2024")

 for chunk in client.runs.stream(
     None,  # Threadless run
     "agent", # Name of assistant. Defined in langgraph.json.
     input={
         "messages": [{
             "role": "human",
             "content": "What is LangGraph?",
         }],
     },
     stream_mode="messages-tuple",
 ):
     print(f"Receiving new event of type: {chunk.event}...")
     print(chunk.data)
     print("\n\n")
bash
curl -s --request POST \
    --url "http://localhost:2024/runs/stream" \
    --header 'Content-Type: application/json' \
    --data "{
        \"assistant_id\": \"agent\",
        \"input\": {
            \"messages\": [
                {
                    \"role\": \"human\",
                    \"content\": \"What is LangGraph?\"
                }
            ]
        },
        \"stream_mode\": \"messages-tuple\"
    }"
