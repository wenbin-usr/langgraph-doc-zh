使用 Functional API 进行流式输出

从 Functional API 入口点发出自定义进度，或从 values 流中读取状态快照。

有两种方式可以从 Functional API 的入口点进行流式输出。自定义数据是一条旁路通道：你用 writer 推送进度，然后读取 custom 数据块。values 是运行时记录的状态快照，包括入口点的返回值。对于 values，你无需调用 writer。

关于概念，请参阅 Functional API 概览。关于消息及其他类型化投影，请参阅事件流式输出。

发出自定义数据#

Functional API 使用与 Graph API 相同的流。用 writer 发出数据，然后消费 custom 数据块。关于流模式，请参阅流式输出。

python
from langchain_core.utils.uuid import uuid7
from langgraph.checkpoint.memory import InMemorySaver
from langgraph.config import get_stream_writer
from langgraph.func import entrypoint

checkpointer = InMemorySaver()


@entrypoint(checkpointer=checkpointer)
def main(inputs: dict) -> int:
    writer = get_stream_writer()
    writer("Started processing")
    result = inputs["x"] * 2
    writer(f"Result is {result}")
    return result


config = {"configurable": {"thread_id": str(uuid7())}}

for chunk in main.stream({"x": 5}, config, stream_mode="custom"):
    print(chunk)
# Started processing
# Result is 10
查看示例 trace

打开此示例对应的公开 LangSmith 运行记录。

  1. 从 langgraph.config 导入 1。
  2. 在入口点内部调用它，以获得一个 writer。
  3. 在计算前后发出自定义数据。
  4. 调用 stream(..., stream_mode="custom") 并迭代数据块。
⚠警告

Python \< 3.11 下的异步 在 Python \< 3.11 的异步代码中，0 无法使用。请改用可注入的 StreamWriter 参数。请参阅 Python \< 3.11 下的异步。

python
from langgraph.checkpoint.memory import InMemorySaver
from langgraph.func import entrypoint
from langgraph.types import StreamWriter

checkpointer = InMemorySaver()

@entrypoint(checkpointer=checkpointer)
async def main(inputs: dict, writer: StreamWriter) -> int:
    writer("Started processing")
    return inputs["x"] * 2

流式输出 values#

复用发出自定义数据中的 main 入口点。迭代 stream.values 以获取状态快照。关于消息及其他投影，请参阅事件流式输出。

python
values_config = {"configurable": {"thread_id": str(uuid7())}}
stream = main.stream_events({"x": 5}, config=values_config, version="v3")
for snapshot in stream.values:
    print(snapshot)
# 10
