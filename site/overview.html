LangGraph 概述

面向长时间运行、有状态智能体的低层编排框架与运行时

LangGraph 是一个用于长时间运行、有状态智能体的低层编排框架与运行时。你将工作流定义为由共享状态、节点和边构成的图，并可以在同一个图中混用确定性步骤与由 LLM 驱动的步骤。

LangGraph 专注于编排能力，例如持久执行、流式输出和人在回路。它不规定提示词或智能体架构。

在开始之前，先了解智能体使用的构建块，尤其是模型和工具。文档示例通常使用 LangChain 完成这些集成，但 LangGraph 并不要求使用 LangChain。

如果你更希望先使用更高层的智能体循环，请使用 Deep Agents 或 LangChain 智能体。当你需要对状态和控制流进行显式控制时，请使用 LangGraph。

LangChain 各产品如何协同工作

  • Deep Agents 是一个智能体运行框架：在 LangGraph 之上提供规划、子智能体、文件系统工具和上下文管理。
  • LangChain 是智能体框架：为模型、工具和智能体循环提供抽象与集成。
  • LangGraph 是编排运行时：持久执行、流式输出、人在回路和持久化。
  • LangSmith 是跨框架进行追踪、评估、提示词和部署的平台。
  • LangSmith Engine 会检测 LangGraph 智能体追踪中的问题并给出修复建议。你可以在 Engine 标签页中针对建议的修复发起拉取请求。
  • LangSmith Fleet 是零代码智能体构建器，用于模板、集成和例行自动化。

关于开源技术栈的对比，请参阅框架、运行时与运行框架。

安装#

bash
pip install -U langgraph
bash
uv add langgraph

创建一个最小的图：

python
from langgraph.graph import StateGraph, MessagesState, START, END

def mock_llm(state: MessagesState):
    return {"messages": [{"role": "ai", "content": "hello world"}]}

graph = StateGraph(MessagesState)
graph.add_node(mock_llm)
graph.add_edge(START, "mock_llm")
graph.add_edge("mock_llm", END)
graph = graph.compile()

graph.invoke({"messages": [{"role": "user", "content": "hi!"}]})

如需完整的计算器智能体，请参阅 LangGraph 快速入门。

能力#

LangGraph 提供了面向有状态、长时间运行工作流的运行时基础原语。它不对提示词做抽象，也不强制固定的智能体架构。

  • 确定性步骤与智能体步骤：在一个图中将手写节点与模型驱动的节点组合起来。
  • 持久化：对状态做检查点，并在失败或暂停后恢复。
  • 人在回路：暂停执行，检查或编辑状态，然后继续。
  • 记忆：短期线程状态与跨会话的长期记忆。
  • 流式输出：在图运行过程中流式输出 token、状态更新和其他事件。

集成、部署与可观测性#

LangGraph 可以独立使用。不过，你也可以将它与其他 LangCHain 产品搭配使用：

LangChain

基于 LangGraph 构建的集成与智能体抽象。

LangSmith Deployment

部署并扩展有状态智能体，并可在 Studio 中进行可视化原型设计。

LangSmith Observability

追踪请求、评估输出并监控部署。
