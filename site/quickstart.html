LangGraph/入门/快速开始
入门

快速开始

本快速开始演示如何使用 LangGraph Graph API 或 Functional API 构建一个计算器智能体。

💡提示

使用 AI 编程助手？

  • 安装 LangChain 文档 MCP 服务器，让你的智能体能够访问最新的 LangChain 文档和示例。

    连接 LangChain 文档 MCP 服务器

    将两个 LangChain 文档 MCP 服务器都连接到我的编程智能体，以便它可以查询最新的 LangChain、LangGraph 和 LangSmith 文档及 API 参考。

    要添加的服务器：

    • docs-langchain: https://docs.langchain.com/mcp
    • reference-langchain: https://reference.langchain.com/mcp

    检测我正在使用哪个智能体或编辑器（Claude Code、Cursor、Codex CLI、Claude Desktop、Deep Agents Code、VS Code、Antigravity 或其他兼容 MCP 的客户端）。使用 https://docs.langchain.com/use-these-docs.md 中对应的配置：

    • Claude Code：为每个服务器运行 claude mcp add --transport http（默认项目范围；仅当我要求全局访问时才使用 --scope user）。
    • Codex CLI：使用每个服务器的 URL 运行 codex mcp add。
    • Cursor、Deep Agents Code、VS Code 或 Antigravity：使用该页面上为我的客户端显示的字段名，将两个条目合并到 MCP 设置 JSON 中。
    • Claude Desktop：在 Settings > Connectors 下添加两个 URL。

    不要臆造其他 MCP URL。配置完成后，确认两个服务器都已列出且可访问。

  • 安装 LangChain Skills，以提升你的智能体在 LangChain 生态任务上的表现。

    安装 LangChain Skills

    为我的编程智能体安装 LangChain Skills，以便它在 LangChain、LangGraph 和 Deep Agents 任务上表现更好。

    使用 https://github.com/langchain-ai/langchain-skills 中的 Agent Skills 安装程序：

    bash
    npx skills add langchain-ai/langchain-skills --skill '*' --yes

    如果我要求全局安装，请改用：

    bash
    npx skills add langchain-ai/langchain-skills --skill '*' --yes --global

    检测我正在使用哪个智能体或编辑器。如果我使用 Claude Code 并偏好插件方式，请按照该仓库 README 中的市场安装流程操作（先 /plugin marketplace add，再 /plugin install）。不要臆造其他 skill 包名或安装 URL。安装完成后，确认智能体可以使用这些 skills。

前提条件#

在开始之前，请确保你拥有来自模型提供商的 API 密钥（例如 Gemini、Anthropic、OpenAI）。 有关所有可用的提供商，请参阅聊天模型集成。

如果你使用 LangSmith Gateway，可以自带提供商密钥，或使用 Gateway Credits 在没有提供商密钥的情况下访问模型。

设置#

安装 langgraph、langchain 和 langchain-anthropic：

bash
pip install -U langgraph langchain langchain-anthropic
bash
uv add langgraph langchain langchain-anthropic

本示例使用 Anthropic。在 shell 或 .env 文件中设置你的 API 密钥：

bash
export ANTHROPIC_API_KEY="your-api-key"
bash
ANTHROPIC_API_KEY=your-api-key

要使用其他提供商，请参阅聊天模型集成，并在后续步骤中调整模型初始化。

1. 选择 API#

两种方式构建的是同一个计算器智能体：模型可以调用工具，然后智能体再次调用模型，直到返回最终答案。

  • 如果你希望将智能体定义为由节点和边构成的图，请使用 Graph API。
  • 如果你希望将智能体定义为单个函数，请使用 Functional API。

选择一个标签页。创建一个文件。将以下每个步骤的代码依次添加到上一步代码的下方。

不确定该选哪个？请参阅在 Graph API 与 Functional API 之间选择。有关概念性信息，请参阅 Graph API 概览 和 Functional API 概览。

构建 LangGraph Graph API 计算器快速入门

按照 LangGraph 快速入门，在当前工作目录中使用 Graph API 构建一个 LangGraph 计算器智能体。

  • Python: https://docs.langchain.com/oss/python/langgraph/quickstart.md
  • TypeScript: https://docs.langchain.com/oss/javascript/langgraph/quickstart.md

只使用 使用 Graph API 标签页。不要实现 Functional API 路径。

使用该项目中已有的包管理器，安装 Graph API 路径所需的包。

第 3 步：配置模型凭据#

本快速入门默认使用 Anthropic。检查是否已设置 ANTHROPIC_API_KEY。如果未设置，请用户创建密钥并在 shell 或 .env 文件中设置，然后停下并等待确认。不要编造、硬编码或提交 API 密钥。如果用户根据集成文档更倾向于使用其他聊天模型提供商，请在确认后相应调整示例。

使用指南中的示例算术查询调用智能体，并打印最终结果。

2. 定义工具和模型#

本示例使用 Claude Sonnet 模型，并定义加法、乘法和除法工具。

为智能体创建文件（agent.py 或 agent.ts）。添加以下内容：

python
from langchain.tools import tool
from langchain.chat_models import init_chat_model


model = init_chat_model(
    "claude-sonnet-4-6",
    temperature=0
)


# Define tools
@tool
def multiply(a: int, b: int) -> int:
    """Multiply `a` and `b`.

    Args:
        a: First int
        b: Second int
    """
    return a * b


@tool
def add(a: int, b: int) -> int:
    """Adds `a` and `b`.

    Args:
        a: First int
        b: Second int
    """
    return a + b


@tool
def divide(a: int, b: int) -> float:
    """Divide `a` and `b`.

    Args:
        a: First int
        b: Second int
    """
    return a / b


# Augment the LLM with tools
tools = [add, multiply, divide]
tools_by_name = {tool.name: tool for tool in tools}
model_with_tools = model.bind_tools(tools)

3. 定义状态#

图的状态存储消息和 LLM 调用次数。

在工具和模型下方添加以下内容：

💡提示

LangGraph 中的状态会在智能体的整个执行过程中持久保留。

配合 operator.add 的 Annotated 类型会把新消息追加到列表中，而不是替换列表。

python
from langchain.messages import AnyMessage
from typing_extensions import TypedDict, Annotated
import operator


class MessagesState(TypedDict):
    messages: Annotated[list[AnyMessage], operator.add]
    llm_calls: int

4. 定义模型节点#

模型节点调用 LLM，并决定是否调用工具。

在状态 schema 下方添加以下内容：

python
from langchain.messages import SystemMessage


def llm_call(state: dict):
    """LLM decides whether to call a tool or not"""

    return {
        "messages": [
            model_with_tools.invoke(
                [
                    SystemMessage(
                        content="You are a helpful assistant tasked with performing arithmetic on a set of inputs."
                    )
                ]
                + state["messages"]
            )
        ],
        "llm_calls": state.get('llm_calls', 0) + 1
    }

5. 定义工具节点#

工具节点调用工具并返回结果。

在模型节点下方添加以下内容：

python
from langchain.messages import ToolMessage


def tool_node(state: dict):
    """Performs the tool call"""

    result = []
    for tool_call in state["messages"][-1].tool_calls:
        tool = tools_by_name[tool_call["name"]]
        observation = tool.invoke(tool_call["args"])
        result.append(ToolMessage(content=observation, tool_call_id=tool_call["id"]))
    return {"messages": result}

6. 定义结束逻辑#

条件边函数根据 LLM 是否发起工具调用，路由到工具节点或结束。

在工具节点下方添加以下内容：

python
from typing import Literal
from langgraph.graph import StateGraph, START, END


def should_continue(state: MessagesState) -> Literal["tool_node", END]:
    """Decide if we should continue the loop or stop based upon whether the LLM made a tool call"""

    messages = state["messages"]
    last_message = messages[-1]

    # If the LLM makes a tool call, then perform an action
    if last_message.tool_calls:
        return "tool_node"

    # Otherwise, we stop (reply to the user)
    return END

7. 构建并编译智能体#

在路由函数下方添加以下内容。使用 0 构建图，并使用 1 编译它：

python
# Build workflow
agent_builder = StateGraph(MessagesState)

# Add nodes
agent_builder.add_node("llm_call", llm_call)
agent_builder.add_node("tool_node", tool_node)

# Add edges to connect nodes
agent_builder.add_edge(START, "llm_call")
agent_builder.add_conditional_edges(
    "llm_call",
    should_continue,
    ["tool_node", END]
)
agent_builder.add_edge("tool_node", "llm_call")

# Compile the agent
agent = agent_builder.compile()

8. 设置 LangSmith 追踪#

LangSmith 会在智能体运行时展示工具调用和模型响应。

此步骤是可选的。在 smith.langchain.com 注册、创建 API 密钥，并在运行智能体之前于 shell 中设置以下环境变量：

bash
export LANGSMITH_TRACING=true
export LANGSMITH_API_KEY="your-langsmith-api-key"

9. 运行智能体#

在编译后的图下方添加以下内容：

python
from langchain.messages import HumanMessage

messages = [HumanMessage(content="Add 3 and 4.")]
messages = agent.invoke({"messages": messages})
for m in messages["messages"]:
    m.pretty_print()

运行该文件：

bash
python agent.py

你应当会看到人类消息、对 add 的工具调用、工具结果 7，以及最终的助手回复。具体文本因模型而异，但工具结果是 7。

3. 定义模型任务#

模型任务调用 LLM，并决定是否调用工具。

在工具和模型下方添加以下内容：

💡提示

0 装饰器将函数标记为智能体中的任务。可以在入口点中同步或异步调用任务。

python
@task
def call_llm(messages: list[BaseMessage]):
    """LLM decides whether to call a tool or not"""
    return model_with_tools.invoke(
        [
            SystemMessage(
                content="You are a helpful assistant tasked with performing arithmetic on a set of inputs."
            )
        ]
        + messages
    )

4. 定义工具任务#

工具任务调用工具并返回结果。

在模型任务下方添加以下内容：

python
@task
def call_tool(tool_call: ToolCall):
    """Performs the tool call"""
    tool = tools_by_name[tool_call["name"]]
    return tool.invoke(tool_call)

5. 定义智能体#

在任务下方添加以下内容。使用 0 定义智能体：

ℹ注意

Functional API 在单个函数中使用普通控制流（循环和条件语句），而不是显式的节点和边。

python
@entrypoint()
def agent(messages: list[BaseMessage]):
    model_response = call_llm(messages).result()

    while True:
        if not model_response.tool_calls:
            break

        # Execute tools
        tool_result_futures = [
            call_tool(tool_call) for tool_call in model_response.tool_calls
        ]
        tool_results = [fut.result() for fut in tool_result_futures]
        messages = add_messages(messages, [model_response, *tool_results])
        model_response = call_llm(messages).result()

    messages = add_messages(messages, model_response)
    return messages

tools_by_name = {tool.name: tool for tool in tools}
model_with_tools = model.bind_tools(tools)

from langgraph.graph import add_messages
from langchain.messages import (
    SystemMessage,
    HumanMessage,
    ToolCall,
)
from langchain_core.messages import BaseMessage
from langgraph.func import entrypoint, task


# Step 3: Define model task

@task
def call_llm(messages: list[BaseMessage]):
    """LLM decides whether to call a tool or not"""
    return model_with_tools.invoke(
        [
            SystemMessage(
                content="You are a helpful assistant tasked with performing arithmetic on a set of inputs."
            )
        ]
        + messages
    )


# Step 4: Define tool task

@task
def call_tool(tool_call: ToolCall):
    """Performs the tool call"""
    tool = tools_by_name[tool_call["name"]]
    return tool.invoke(tool_call)


# Step 5: Define agent

@entrypoint()
def agent(messages: list[BaseMessage]):
    model_response = call_llm(messages).result()

    while True:
        if not model_response.tool_calls:
            break

        # Execute tools
        tool_result_futures = [
            call_tool(tool_call) for tool_call in model_response.tool_calls
        ]
        tool_results = [fut.result() for fut in tool_result_futures]
        messages = add_messages(messages, [model_response, *tool_results])
        model_response = call_llm(messages).result()

    messages = add_messages(messages, model_response)
    return messages

# Step 6: Set up LangSmith tracing (optional)
# export LANGSMITH_TRACING=true
# export LANGSMITH_API_KEY="your-langsmith-api-key"

# Step 7: Run the agent
messages = [HumanMessage(content="Add 3 and 4.")]
messages = agent.invoke(messages)
for m in messages:
    m.pretty_print()
